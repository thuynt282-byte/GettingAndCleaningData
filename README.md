# Getting and Cleaning Data – Course Project

## 1. Project Overview

This project is part of the Getting and Cleaning Data course.

The objective is to collect, clean, and prepare a tidy dataset using the Human Activity Recognition Using Smartphones (UCI HAR) Dataset.

The project combines the training and test datasets, extracts measurements of mean and standard deviation, and calculates the average of each measurement for every subject and activity.

## 2. Dataset

**Dataset:** Human Activity Recognition Using Smartphones

**Source:** UCI Machine Learning Repository

**URL:** https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones

The dataset contains measurements collected from 30 volunteers performing six activities while wearing a smartphone.
